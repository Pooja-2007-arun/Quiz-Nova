## 🌟 About The Project

**QuizNova** is a browser-based quiz game designed to make learning fun while challenging your brain.

Whether you love solving math problems, testing your memory, or exploring interesting facts, QuizNova offers an exciting way to challenge yourself and track your performance.

This project was built using HTML, CSS, and JavaScript as part of my web development portfolio.

---

## 🎯 Game Modes

| Mode | Description |
|---|---|
| 🧠 Memory Challenge | Memorize number sequences and test how much you can remember. |
| 🔢 Math Challenge | Solve random math questions and sharpen your calculation skills. |
| 🌍 General Knowledge | Explore fun facts and test your knowledge across different topics. |

---

## ✨ Features

- 🎮 Three interactive game modes
- 🏆 Score tracking with points for correct answers
- 📊 Final results showing correct answers, wrong answers, and accuracy
- 🔄 Play Again option to restart a challenge
- 💾 Best score saved locally in your browser
- 📱 Responsive design for desktop and mobile screens
- 🎨 Modern dark-themed interface with vibrant colors

## 🚀 Getting Started

Want to run QuizNova on your computer?

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/QuizNova.git
```

### 2. Navigate to the project folder

```bash
cd QuizNova
```

### 3. Launch the game

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

No additional packages or installations are required.
